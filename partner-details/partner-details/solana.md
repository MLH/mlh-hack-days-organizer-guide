# Solana

**Last reviewed:** August 2026

Solana supports Major League Hacking and the Hack Days program with a fast, efficient development layer for applications. Its documentation, tutorials, and templates help hackers get started quickly while Solana provides the backend for what they build.

## Best Use of Solana

It’s time to turn an ambitious idea into an application built to move quickly. Use Solana as the development layer for your project and let it handle the scale and reliability while your team focuses on the experience. So, what can you build with Solana?

* Create an interactive application that uses onchain state, ownership, or transactions
* Build a community, gaming, creator, payments, or finance experience powered by Solana
* Connect a web or mobile application to Solana as a fast, efficient backend

Use Solana to power something people will want to try… what will you build today?

## Judging Evidence

Confirm that the winning project actually uses Solana. Ask the team to identify the integration in its README and show the relevant code, configuration, transaction, deployed program, or other appropriate evidence during the demonstration.
